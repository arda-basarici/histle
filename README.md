# histle

**Guess the historical event. Every wrong guess tells you how far off you are — in
centuries, continents, and kind.**

A daily browser game: one hidden famous historical event; the player guesses other
events and triangulates from multi-axis feedback (time distance + direction, region,
category). The Globle mechanic, transposed from countries to events.

> Pre-build. The design is settled (see DESIGN.md); nothing is playable yet. This
> README grows with the build and claims nothing ahead of it.
